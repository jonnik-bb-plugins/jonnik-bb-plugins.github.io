# jonnik-bb-plugins.github.io

Static one-page site listing the bb plugins by JonniK: https://jonnik-bb-plugins.github.io/
To add a plugin, copy a `<article class="card">` block in `index.html` and edit it. No build step.
Screenshots and the Skill Dial, Bottom Panel and Claude Code Mode icons live in `assets/<plugin-id>/` (copied from the bb catalog). Session MRs and Bang Shell icons are inline SVGs from [Lucide](https://lucide.dev) (ISC license).
